# Spectral curves from three body regions of stripe-tailed yellow finch (*Sicalis citrina*) males

Dataset containing reflectance measurements from 3 body parts ("C":
crown, "B": breast, "T": throat) from seven male stripe-tailed yellow
finches (*Sicalis citrina*)

## Usage

``` r
data(sicalis)
```

## Format

An object of class `rspec` (inherits from `data.frame`) with 401 rows
and 22 columns.
